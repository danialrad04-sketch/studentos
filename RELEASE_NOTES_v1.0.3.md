# Student OS v1.0.3 — Bazaar Review Access Hotfix

## Review access
- Fresh installations can enter and use the app without authentication.
- Guest mode is enabled by default only when no prior guest preference exists and the first launch has not been completed.
- Existing users keep their stored authentication/guest choice.
- Firebase Google Sign-In remains available from the account flow.

## Important
This is a review/access hotfix for the v1.x release line. It does not change the production signing identity or Firebase project configuration.
