# نسخهٔ ۳.۰.۱ — ساخت ۲۰۲۱

🎨 چیدمان مرتب‌تر کارت‌ها، پنجره‌ها و تنظیمات در تم روشن و تیره
📅 بازطراحی برنامهٔ هفتگی و نمایش کلاس‌ها در تمام بازه‌های ثبت‌شده
📝 نمایش خواناتر نام درس‌ها، تکلیف‌ها و اطلاعات کلاس
🔢 ورودی عددی بهتر، پیام ذخیره و خطاهای واضح‌تر
💡 راهنمای جمع‌شونده با امکان مشاهدهٔ دوباره

این بسته برای تست و بررسی است؛ انتشار یا تأیید بازار را اعلام نمی‌کند.
