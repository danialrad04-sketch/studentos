# Student OS 2.3.0 — آماده‌سازی Student Pro

- خرید و بازیابی اشتراک از طریق SDK رسمی پولکی بازار؛ فعال‌سازی فقط پس از تأیید سرور.
- اتصال پاسخ آنلاین و اسکن برنامه به Firebase Functions، بدون قراردادن کلید سرویس در APK.
- ابزارهای پرو: مربی مطالعهٔ هفت‌روزه، نقشهٔ مرور امتحان و تحلیل پیشرفت؛ سهمیهٔ ۵۰ پاسخ و ۱۰ اسکن روزانه.
- صفحهٔ اشتراک جدید با مبلغ کل دوره، وضعیت خرید، بازیابی و تاریخ پایان دسترسی.
- چیدمان خلوت‌تر خانه، میان‌برهای خوانا، دسته‌بندی ابزارها و تایپوگرافی بزرگ‌تر.
- استفاده از برنامه، تکالیف و داده‌های محلی در حالت مهمان ادامه دارد.

فروش تا تکمیل تنظیمات سرور، تعریف محصولات بازار و تست واقعی دستگاه غیرفعال می‌ماند. قیمت پیشنهادی بر مبنای نرخ‌های منتشرشده در راهنمای مالی بازار است و باید با قرارداد و نرخ جاری حساب ناشر تطبیق داده شود.
