# Student OS ۲.۴.۱ — استفاده بدون حساب

- شروع برنامه و تنظیم مشخصات دانشجو بدون نیاز به ورود، Firebase یا اینترنت.
- ورود و ثبت‌نام آنلاین موقتاً برای همهٔ کاربران این نسخه غیرفعال است؛ مسیر شکست‌خوردهٔ ساخت حساب نمایش داده نمی‌شود.
- امکانات محلی برنامهٔ کلاسی، تکالیف، امتحان‌ها، حضور و غیاب، کارنامه و پشتیبان فایل همچنان در دسترس هستند.
- برای کاربران مهمان، خدمات نیازمند حساب شامل خرید اشتراک، پاسخ آنلاین دستیار و تیکت آنلاین با توضیح روشن عدم دسترسی نمایش داده می‌شوند.
- حساب‌های متصل قبلی، کد Firebase و بک‌اند، شناسهٔ بسته و امضای اصلی حفظ شده‌اند.

نسخه: ۲.۴.۱ / کد ۲۰۱۱. رفع خطای زیرساخت Firebase یا دسترسی شبکه ادعا نمی‌شود؛ این نسخه برای استفادهٔ محلی به آن وابسته نیست.
