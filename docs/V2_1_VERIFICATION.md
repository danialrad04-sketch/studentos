## Fixed release blockers discovered by this audit

- Instrumentation did not compile due to invalid fetchSemanticsNode import and missing dp import.
- Gradle ignored VERSION_CODE and VERSION_NAME passed by workflows.
- Release checked the dispatch SHA instead of the checked-out SHA and only one CI job.
- Old workflow required an undeployed private backend despite guest/Firebase release scope.
- Backend session restore and subscription upgrade could grant unverified privileges.
- Account deletion ignored Result failures; cloud subcollection deletion swallowed errors.
- Next-class tile invented class times, treated Friday as Saturday and opened the first course.
- Cloud sync reported full success when only one direction succeeded.
- Backend sync worker marked success while ignoring failed Result values.

## Production decision

NOT production-certified. A green pipeline is necessary, but does not prove live Google
login, production Firestore rules, actual device accessibility, upgrade data retention,
or Bazaar listing approval. Publish only after those checks have recorded evidence.
Do not replace the signing key or publish a fresh unrelated application ID.
