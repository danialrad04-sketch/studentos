# Bazaar Review Access — Student OS 2.0.1

## Reviewer path
1. Install the APK.
2. The app opens directly in local guest mode; no network login is required.
3. Add or inspect courses, schedule, tasks, exams, attendance and grades.
4. Open Account to test optional Email/Firebase or Google authentication.
5. Online authentication requires a working network path to Firebase/Google.

## Review note
Student OS does not require authentication for the core offline-first experience. Account login is optional and is used for cloud synchronization/account features.
