# راه‌اندازی دستیار؛ فقط برای صاحب برنامه

کاربران برنامه هیچ کلید، حساب OpenAI یا تنظیم سروری وارد نمی‌کنند. این کار یک بار توسط صاحب برنامه انجام می‌شود. پروژهٔ فعلی Firebase همان `dani-87c77` می‌ماند؛ پروژه یا حساب‌های قبلی را حذف و جایگزین نکن.

وضعیت اعلام‌شدهٔ مالک در ۲۰۲۶/۱۰/۲۶: دسترسی Firebase هست؛ حساب API هنوز آماده نیست. بررسی عمومی آدرس تابع دستیار در همین تاریخ پاسخ HTTP 404 داد. این بررسی، فعال‌بودن یا خاموش‌بودن تمام سرویس‌های پروژه را ثابت نمی‌کند؛ اتصال آنلاین برنامه هنوز با پاسخ واقعی تأیید نشده است.

## ۱. حساب سرویس مدل را آماده کن

- در [پلتفرم API OpenAI](https://platform.openai.com/) حساب بساز یا وارد حساب موجود شو.
- در بخش Billing، روش پرداخت و اعتبار مصرف API را آماده کن. اشتراک ChatGPT جای اعتبار API نیست. هزینهٔ استفادهٔ کاربران برنامه از حساب صاحب برنامه پرداخت می‌شود.
- یک پروژهٔ مخصوص Student OS بساز. کلید مخصوص همان پروژه را در بخش API keys بساز و در جای امن نگه دار.
- برای کنترل هزینه، هشدار مصرف و محدودیت‌های موجود حساب را تنظیم کن. هشدار بودجهٔ ارائه‌دهنده الزاماً سقف قطعی هزینه نیست. سرور برنامه نیز سقف درخواست روزانه دارد.

**کلید را در گفتگو، گیت‌هاب، APK یا فایل عمومی نفرست.** محل ورود آن، ورودی امن Firebase CLI در مرحلهٔ ۳ است. اگر حساب OpenAI برایت قابل استفاده نیست، فقط نام سرویس جایگزین، نشانی API و مدلش را اعلام کن؛ سرور از سرویس‌های سازگار پشتیبانی می‌کند و کلید همچنان خصوصی می‌ماند.

## ۲. همان Firebase را آماده کن

در [کنسول Firebase](https://console.firebase.google.com/) پروژهٔ `dani-87c77` را باز کن:

1. برای اجرای Cloud Functions، صورتحساب و طرح Blaze همان پروژه باید آماده باشد. ممکن است هزینهٔ Functions و سرویس‌های همراه جدا از هزینهٔ مدل باشد.
2. در Authentication → Sign-in method، روش Anonymous را فعال کن. نشست دستیار خودکار و جدا از حساب اصلی دانشجوست؛ ورود یا داده‌های فعلی را تغییر نده.
3. App Check را برای برنامهٔ اندروید موجود با بستهٔ `com.aistudio.studentos.appvzk` و گواهی تولید تنظیم کن. SHA-256 گواهی: `a335e71031ec78a7961656b2c36d8c53abcb3bdc28e265998cf6053fb94eb950`.
4. برای نصب خارج از Google Play مثل بازار، تنظیمات پیشرفتهٔ Play Integrity را مطابق [راهنمای رسمی Firebase](https://firebase.google.com/docs/app-check/android/play-integrity-provider) انتخاب کن: الزام‌های `PLAY_RECOGNIZED` و `LICENSED` برای توزیع انحصاری خارج از Play مناسب نیستند؛ تنظیم `DEVICE_INTEGRITY` را بررسی کن. App Check را در کد خاموش نکن.

## ۳. کلید را خصوصی ثبت و دو تابع را مستقر کن

روی رایانهٔ خودت، با Node.js 22 و یک نسخه از مخزن، از ریشهٔ پروژه اجرا کن:

```sh
npm --prefix functions ci --ignore-scripts --no-audit --no-fund
npm --prefix functions exec -- firebase login
npm --prefix functions run ai:setup -- --check
npm --prefix functions run ai:setup -- --deploy
```

فرمان `--check` فقط برنامهٔ کار و پیش‌نیازها را چاپ می‌کند؛ بررسی آنلاین صورتحساب یا سلامت سرویس نیست. فرمان `--deploy` کلید را در ورودی امن Secret Manager می‌گیرد؛ **کلید را به انتهای فرمان اضافه نکن**. تنظیمات مدل OpenAI از قبل آماده‌اند. ابزار، تنظیمات نامرتبط موجود را حفظ می‌کند و فقط `getAcademicAiStatus` و `generateAcademicAssistantReply` را مستقر می‌کند؛ باقی توابع، حساب‌ها و داده‌ها حفظ می‌شوند.

اگر اینجا دسترسی استقرار امن برای دستیار کاری فراهم نشده باشد، ورود Firebase را روی رایانهٔ خودت انجام بده؛ فایل حساب سرویس، توکن ورود یا رمز حساب را در گفتگو نفرست.

## ۴. اتصال واقعی را تأیید کن

نسخهٔ امضاشدهٔ برنامه را روی دستگاه سازگار نصب کن و از صفحهٔ دستیار، با اطلاعات آزمایشی یک پرسش ساده بفرست. باید پاسخ مدل و وضعیت اتصال آنلاین مشخص شود. قطع اینترنت، تلاش دوباره و سهمیه را هم بررسی کن. ساخته‌شدن APK، موفقیت تست شبیه‌سازی‌شده یا حتی موفقیت فرمان استقرار، به‌تنهایی دریافت پاسخ واقعی از مدل را ثابت نمی‌کند.

برای ادامهٔ کار، فقط نتیجهٔ هر مرحله و متن خطای بدون اطلاعات محرمانه را اعلام کن: «حساب API آماده شد»، «Blaze آماده است»، «Anonymous فعال است»، «App Check تنظیم شد»، «استقرار موفق شد». تنظیمات فنی بیشتر، آزمون مستقیم ارائه‌دهنده و نکات سهمیه در [راهنمای کامل](AI_SETUP_FA.md) آمده است.
