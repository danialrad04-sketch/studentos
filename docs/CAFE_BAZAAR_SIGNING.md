# راهنمای فایل‌های انتشار در کافه‌بازار

برای انتشار نسخهٔ ۲.۲.۰ از مسیر App Bundle در پیشخان بازار، این دو فایل را با هم بارگذاری کنید:

- `StudentOS-2.2.0.aab`: همان باندل امضاشدهٔ ریلیز عمومی.
- `StudentOS-2.2.0.bin`: امضاهای بسته‌های استخراج‌شده از همان باندل، تولیدشده با ابزار رسمی بازار.

هر دو در `CafeBazaar-2.2.0.zip` نیز قرار دارند. ZIP را ابتدا استخراج کنید؛ فایل ZIP جای AAB/BIN در پیشخان نیست.
برای مسیر APK، فایل `StudentOS-2.2.0.apk` ریلیز عمومی از قبل با کلید تولید امضا شده است.
BIN نسخهٔ ۱.۰.۲ برای نسخهٔ جدید قابل استفاده نیست؛ به محتوای همان AAB وابسته است.

شناسه بسته: `com.aistudio.studentos.appvzk`، نسخه `2.2.0`، کد نسخه `2008`.
کلید خصوصی یا رمزهای آن نباید در پیشخان یا ریلیز عمومی بارگذاری شوند.

## روش رسمی و تکرارپذیر

مرجع رسمی: https://developers.cafebazaar.ir/fa/guidelines/feature/app_bundle

ابزار رسمی و راهنمای قابل خواندن: https://github.com/cafebazaar/bundle-signer

نسخه ابزار: `0.1.13`؛ تنظیمات مطابق خط انتشار موفق نسخهٔ ۱.۰.۲: `v2=true` و `v3=false`.
صفحهٔ راهنمای سایت بازار در ابزار بازیابی متن فقط Loading برمی‌گرداند؛ دستورها از README و سورس رسمی خود بازار بررسی شده‌اند.

اسکریپت `scripts/generate_bazaar_bin.sh` از کلید تولید موجود استفاده می‌کند، گواهی AAB و کلید را کنترل می‌کند،
BIN را برای همان AAB می‌سازد و با ابزار رسمی، APKهای حاصل از AAB/BIN را بازسازی و امضای همه را بررسی می‌کند.
ورودی AAB تغییر نمی‌کند. رمزها فقط از محیط امن GitHub Actions خوانده می‌شوند.

اثر انگشت SHA-256 گواهی تولید:
`a335e71031ec78a7961656b2c36d8c53abcb3bdc28e265998cf6053fb94eb950`

خط انتشار معمول فایل BIN را همراه APK/AAB می‌سازد. گردش‌کار دستی `Add Cafe Bazaar Signing Assets`
برای افزودن BIN به یک ریلیز موجود است: تگ و SHA کامل همان ریلیز را می‌گیرد، چهار کنترل کیفیت را بررسی می‌کند،
گواهی نسخهٔ ۱.۰.۲ را مقایسه می‌کند و فقط فایل‌های جدید بازار را اضافه می‌کند. APK/AAB قبلی و تگ جایگزین نمی‌شوند.

## پیش از ارسال برای بررسی بازار

- بالاترین versionCode بارگذاری‌شده در پیشخان باید کمتر از `2008` باشد.
- مسیر «ادامه بدون حساب» برای بررسی امکانات آفلاین موجود است.
- ورود Google، همگام‌سازی و حفظ اطلاعات هنگام ارتقا باید روی گوشی واقعی بررسی شوند.
- اطلاعات تماس، سیاست حریم خصوصی، تصاویر نسخهٔ واقعی و اطلاعات فروشگاه در پیشخان تکمیل شوند.
- آماده‌سازی امضا به معنی تضمین پذیرش نهایی یا انتشار در بازار نیست.
